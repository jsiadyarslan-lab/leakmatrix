# LeakMatrix Console — وحدة التحكم

واجهة ويب محلية لأداة LeakMatrix: فحص العبور الأفقي (IDOR/BOLA) عبر مصفوفة
توكن المهاجم × معرفات الضحية من أي مواصفة OpenAPI/Swagger، مع سباق متزامن
وماسح أسرار — للاستخدام على أهداف **مصرّح لك باختبارها فقط** (برنامج Bug
Bounty رسمي أو أنظمتك الخاصة).

## المتطلبات

1. **Node.js 20+** — من nodejs.org أو عبر مدير حزم نظامك
2. **Python 3.10+** مع حزمتين:
   ```bash
   pip install requests pyyaml
   ```

> **بنية المجلدات بعد استنساخ المستودع:** المجلد الجذر يحوي `leakmatrix/`
> (محرك بايثون) و`console/` (هذه الواجهة) و`examples/` — **أبقِ البنية كما
> هي دون نقل console وحده**، فالواجهة تبحث عن المحرك في المجلد الأب
> تلقائيًا. وإن غيّرت البنية فاستخدم متغير البيئة أدناه.

## التشغيل (3 أوامر)

```bash
git clone https://github.com/jsiadyarslan-lab/leakmatrix
cd leakmatrix/console
npm install
npm run dev
```

ثم افتح المتصفح على: **http://localhost:3000**

> ملاحظة ويندوز: الواجهة تكتشف تلقائيًا ما إذا كان أمر بايثون لديك
> `python3` أم `python` — لا حاجة لأي إعداد إضافي.

## أول تجربة — 30 ثانية

1. اضغط زر **«تحميل إعداد الهدف التجريبي الآمن»** — يشغّل هدفاً وهمياً محلياً
   على المنفذ 8791 ويملأ النموذج تلقائيًا
2. علّم **إقرار التفويض**
3. اضغط **«ابدأ المسح»** — وسترى: تسريبين مؤكدين + نقطة محمية + فخ إيجابية
   كاذبة يقتله التحكم التفريقي تلقائيًا

## الاستخدام على هدف حقيقي (مثل Allegro sandbox)

1. انسخ رابط مواصفة OpenAPI/Swagger للهدف (أو الصق محتواها)
2. توكن حسابك = **المهاجم B**، وتوكن/معرفات الحساب الثاني = **الضحية A**
3. التزم بحدود البرنامج: Allegro مثلًا يشترط حد 5 طلبات/ثانية — اضبط شريط
   المعدل على 4 أو أقل، وضع بريد Intigriti في حقل التواصل (يُرسل داخل
   User-Agent)
4. الأداة GET فقط، ولن تضغط زر البدء قبل إقرار التفويض — هذه حدود أخلاقية
   مدمجة تحميك أنت قبل الهدف

## متغيرات البيئة (اختيارية)

| المتغير          | الافتراضي                              | الوظيفة                                       |
| ---------------- | -------------------------------------- | --------------------------------------------- |
| `LEAKMATRIX_HOME`| المجلد الأب (جذر المستودع)             | مسار مجلد محرك بايثون إن غيّرت البنية         |
| `LM_DEMO_PORT`   | `8791`                                 | منفذ الهدف التجريبي المحلي                    |

مثال (PowerShell على ويندوز):

```powershell
$env:LEAKMATRIX_HOME = "C:\tools\leakmatrix"
npm run dev
```

## ملاحظات أمنية

- التوكنات تُستخدم في الذاكرة أثناء المسح فقط ولا تُكتب في أي ملف
- تقرير JSON/CSV يُولّد في متصفحك محليًا
- لا توجّه الأداة أبداً إلى أهداف خارج نطاق تفويضك المكتوب
